# Дизайн-отдел: что оформить первым

Дизайн-скиллы ставятся в Claude Code одной командой по гайду https://maysoulme.ru/design-skills/. После установки напиши Claude Code: «Настрой дизайн-скиллы под мой бренд: фон тёплый молочный, акцент коричневый, шрифты Libre Baskerville и Inter, ник katyamotiv». Дальше по порядку.

1. **Воркбук «Экспресс-тест на деньги» как гайд-страница.** Напиши: «Сделай гайд из этого текста» и вставь текст воркбука. Это то, что выдаёт бот по слову ТЕСТ, поэтому он должен выглядеть дорого с первого экрана.
2. **Восемь презентаций к урокам «Денежного чекапа».** Для каждого урока: «Сделай презентацию к уроку» и вставь описание урока из документа «Продукт» (что показать на экране там уже написано).
3. **Страница продукта.** «Сделай гайд-лендинг по этому офферу» и вставь документ «Оффер». Получится страница, на которую ведёт бот после письма с ценой.
4. **Памятка «День зарплаты».** Одна страница из урока про порядок в день зарплаты: три кармана и первый автоперевод. Её можно отдавать как бонус и показывать в сторис.

Карусели пока не делаем, их добавим отдельным этапом.
