# Пакет помощников Кати (ниша: личные финансы для новичков: лёгкие накопления и денежное мышление)

Собрано 16.10.2026 по данным из пяти документов кабинета: распаковка, аудитория, продукт, оффер, позиционирование. Вместо полных документов в каждого помощника вставлен один короткий «Паспорт» (файл 00_паспорт.md, 800 слов), правила письма вставлены целиком. Каждый файл готов к вставке в любую нейросеть: Claude, ChatGPT, DeepSeek, любую другую.

## Как пользоваться любым файлом

1. Открой нужный файл, скопируй всё от строки «Как пользоваться» до конца (строку «Как пользоваться» можно не копировать, она для тебя).
2. Открой новый чат в нейросети, вставь, отправь.
3. Напиши команду, которая указана в строке «Как пользоваться» этого файла.

Сохрани каждый файл в отдельную заметку на телефоне, тогда кабинет не нужен.

## Порядок обновления

Раз в месяц: сначала обновить паспорт (цифры Кати и Юлианы, цены тарифов, новые фразы аудитории), потом заменить его в каждом файле. Если меняется что-то крупное, документы обновляются в порядке: распаковка, аудитория, продукт, оффер, позиционирование, и только потом паспорт.

## Что в паспорте закреплено как правило достоверности

Цифры только Кати: 1 180 000 ₽ на одном из счетов, около 20 тысяч в месяц выплат (за сентябрь около 17), Юлиана «почти полмиллиона», ученицы «собрали портфели и получили первые выплаты». Должность в блоге не используется, фамилии чужих авторов не называются, цена чекапа 1 290 ₽, цены второго и третьего тарифов на утверждении Кати.
